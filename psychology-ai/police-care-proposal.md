## 1. 3자 관점 문제 분석

### 🚔 경찰관(피해자전담경찰관) 입장

| 문제 | 근거 |
|------|------|
| 업무 과다 | 1인당 월 평균 11.8건, 1건당 행정업무 3건 이상 (서명희 2020) |
| 인력 부족 구조화 | 2·3급지 109개서 정원화 미달, 전국 255개 서 × 1명 |
| 감정 소진 (2차 트라우마) | 민감 사건 반복 노출 → 심리적 스트레스 |
| 사건 폭증 | 고소·고발 반려 폐지(2022.11) 후 전국 사건 접수 37.6% 증가 |
| 전문성 공백 | 임상 심리·상담 교육 부족 상태에서 초기 심리평가 수행 요구 |
| 정보 공백 | KICS 입력 후에만 피해자 인지, 사전 정보 없이 대면 |

> 핵심: "시간·인력·심리 훈련 모두 부족한 상태에서 혼자 초기 면담~기관 연계까지 수행"

### 👤 피해자 입장

| 문제 | 근거 |
|------|------|
| 반복 진술 2차 피해 | 신변보호 요청 등 여러 기관 접촉마다 피해 사실 반복 진술 |
| 대면 부담 | 첫 면담부터 낯선 경찰관 앞에서 진술, 준비 시간 부재 |
| 정보 비대칭 | 자신의 권리·절차를 모르는 상태로 면담 진입 |
| 케어 공백 | 면담 후~다음 면담 사이 심리 지원 부재 |
| 피해 유형 증가 | 스토킹 피해자 2022년 10,545명 → 2024년 13,075명 (+24%) |

> 핵심: "같은 이야기를 여러 번 반복하면서도, 정작 내가 누구와 무엇을 할 수 있는지는 모르는 상태"

### 🏛 행안부·경찰청(운영 주체) 입장

| 문제 | 근거 |
|------|------|
| 제도-현실 격차 | 경찰청 훈령 제932호로 배치했으나 운영 실질화 어려움 |
| 예산·인력 한계 | 정원화 미달 상태 장기 지속 |
| 측정 불가능 | 면담 품질·피해자 만족도 표준화된 측정 도구 부재 |
| 2차 피해 책임 | 국정감사(2024) 행안위에서 스토킹·성폭력 2차 피해 지속 지적 |
| 디지털 전환 압박 | 정책 흐름상 AI·디지털 지원 도입 요구 증가, 프레임워크 부재 |

> 핵심: "제도는 있고 책임은 있는데, 인력·예산·측정 도구가 모두 부족"

## 2. 챗봇의 심리학적 개입 수준 (Tier Model)

```
┌─────────────────────────────────────┐
│  Tier 4 — 진단·약물                 │ ❌ 완전 금지
├─────────────────────────────────────┤
│  Tier 3 — 독립 심리치료             │ ❌ 완전 금지
│  (임상 전문가 자격 요구)            │
├─────────────────────────────────────┤
│  Tier 2.5 — 감독 하 자조/보조 ★신설 │ ⚠️ 조건부 허용 (Phase 2)
│  (임상 감독 + 매뉴얼 + 연계)        │
├─────────────────────────────────────┤
│  Tier 2 — 정서 지원 (PFA)           │ ✅ 주력 1
├─────────────────────────────────────┤
│  Tier 1 — 정보·준비                 │ ✅ 주력 2
└─────────────────────────────────────┘
```

### 심리학적 근거 4축

| 축 | 이론 | 챗봇 적용 |
|----|------|----------|
| 안전감(Safety) | Hobfoll et al. (2007) PFA 5원칙 | Tier 1·2 한정, 즉시 위기 연결 |
| 자기효능감(Self-efficacy) | Bandura (1977) | 권리·절차 안내로 주도성 회복 |
| 사회적 연결(Connectedness) | Hobfoll 5원칙 | 지원기관 연계, 고립감 차단 |
| 진정(Calming) | PFA 8대 활동 (NCTSN, 2006) | 반영적 경청, 감정 수용 |

### 명시적 경계 선언

> 이 챗봇은 Tier 1·2 개입만 수행한다.
> Tier 3·4에 해당하는 신호(자살 의도, PTSD 증상, 복합 트라우마)가 감지되면 **즉시 개입을 중단**하고 인간 전문가에게 연결한다.

## 3. RAG 챗봇의 구조적 한계 — 왜 Tier 1·2가 천장인가

### 상위 티어가 RAG를 회피하는 7가지 이유

| # | 이유 | 내용 |
|---|------|------|
| 1 | 재현성 결여 | 임상시험은 "같은 입력 → 같은 반응" 요구. RAG는 변동 |
| 2 | 환각 임상 치명성 | Tier 3-4에서 환각 = 오진·자살 = 회복 불가 |
| 3 | 감사 가능성 | 룰 기반은 결정 경로 명확, RAG는 불투명 |
| 4 | 임상 검증 비용 폭발 | RAG는 무한 경로 → 전수 검증 불가 |
| 5 | 치료 동맹 일관성 | 같은 환자에 매번 다른 반응 = 라포 붕괴 |
| 6 | 법적 책임 주체 불명 | 설계자? 검색 DB? LLM? |
| 7 | 규제 프레임 부재 | FDA·NICE·식약처 모두 생성형 치료기기 가이드 미정립 |

### 층위별 RAG 적합도

```
Tier 4 (진단)        ❌ 사용 금지 수준
Tier 3 (치료)        ❌ 규제 차단
Tier 2.5 (자조)      △  연구 단계
Tier 2 (정서 지원)    ⭕ 배포 가능 ← 우리 자리
Tier 1 (정보·교육)    ✅ 최적     ← 우리 자리
```

## 5. 기획안 본체

### 5-1. 목적과 측정 지표

| 목적 | 측정 지표 |
|------|----------|
| 피해자 초기 면담 준비도 향상 | 면담 소요 시간 단축 |
| 전담경찰관 정보 공백 해소 | 사전 요약서 전달률 |
| 반복 진술 2차 피해 감소 | 피해자 주관 스트레스 점수 |
| 심리 안정화 | PFA 8대 활동 수행률 |

### 5-2. 대상과 범위

```
대상: KICS 입력 후, 피해자전담경찰관 배정된 피해자
범위: 대면 면담 전 1회 세션 (10턴, 약 15분)
제외: 아동(만18세 미만), 급성 자살 위기자, 복합 트라우마 환자
```

### 5-3. 3단계 로드맵

```
[Phase 1 — 수업 과제 범위]
Module A: 준비 도우미 (Tier 1·2)
└ 현재 RAG v5 그대로

[Phase 2 — 확장 제안]
Module B: 체크인 챗봇 (Tier 1·2 제한적)
  - 면담과 면담 사이 간단 체크인 (3~5턴)
  - 위기 신호 감지 + 기관 연결 트리거만
  - 상담 시도 X, 경청만 O

[Phase 3 — 미래]
KICS 연동 + 경찰 시스템 통합
  - 자동 배정, 요약서 자동 전달
  - 행안부·경찰청 협업 필수
```

### 5-4. 안전장치

| 리스크 | 방어 장치 |
|--------|----------|
| AI 환각 | Tan(2025) 90%이지만 10% 오류 전제 → 규칙 기반 제한 |
| 위기 감지 실패 (39%) | 키워드 기반 즉시 차단 + 인간 전문가 연결 |
| 재트라우마 | 강요 금지 조항, "말하기 어려우면 넘어가도 됨" 매 턴 고지 |
| 법적 책임 | "사전 준비 도우미" 포지션 명시, 진술 효력 없음 명시 |
| 의존성 | 10턴 종료 후 지속 접속 불가 구조 (Phase 1 한정) |

### 5-5. 3자 관점 기대 효과

```
경찰관:    초기 면담 시간 단축 + 사전 정보 확보 + 심리 부담 경감
피해자:    반복 진술 감소 + 권리 사전 인지 + 심리 안정화
행안부:    제도 실질화 + 측정 가능 + 예산 효율성 + 정책 성과 가시화
```

## 6. 발표 핵심 메시지

> **"치료하지 않습니다. 준비시킵니다."**
>
> 이 챗봇은 피해자를 치료하지 않습니다.
> 경찰관의 시간을 벌어주고, 피해자의 말할 용기를 준비시킵니다.
> Tier 1·2 개입에 한정하여 심리학적 근거 위에서 움직이는 사전 면담 도우미입니다.
>
> RAG 기반 챗봇이 의학적으로 배포 가능한 상한선은 Tier 1-2이며,
> 우리는 이 상한선 위에서 피해자 특화 사례를 만들고 있습니다.
