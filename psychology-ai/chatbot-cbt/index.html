현황 — 피해자 지원 사각지대

현재 범죄피해자 심리지원은 피해자가 직접 신청할 경우에만 2~3차례 상담을 제공하는 구조입니다.

이로 인해 중대 범죄 피해자나 응급을 요하는 피해자만 전문 상담사를 만날 수 있고, 그 외 경범죄 피해자는 심리지원 사각지대에 놓입니다.

본 문서의 단계 — PoC

본 챗봇은 PoC(Proof of Concept) 수준입니다. PoC는 "이 메커니즘이 원리적으로 작동하는가?"만 답하는 최소 실험이며, 안정성·사용자 수·상품성은 의도적으로 검증 범위에서 제외합니다.

본 PoC가 답하는 질문:
전담경찰관 면담 후 챗봇이 1회성으로 CBT 한 사이클을 돌려 피해자의 통제감을 회복시킬 수 있는가?

페르소나

대표 페르소나 — 실제 피해 사례 기반

본 페르소나는 가상의 인물이 아니라, 피해자 전담경찰관 2인을 직접 인터뷰하여 들은 실제 피해자 사례를 토대로 구성했습니다. 신원이 드러나지 않도록 세부 정보만 가공했을 뿐, 사건 양상·심리적 반응·일상 붕괴 양상은 인터뷰에서 청취한 그대로입니다.

실제 사례에서 가장 인상 깊었던 점

사건 자체보다 사건 이후의 일상 붕괴(외출 불가 → 직장 상실)가 피해자에게 더 큰 2차 충격을 주었다는 점. 이것이 본 봇의 핵심 개입 지점인 "회피 행동의 점진적 흔들기"의 근거가 되었습니다.

CBT 설계

이론적 기반

이론출처봇 내 역할
인지 재구성Beck (1979)왜곡된 믿음을 흔드는 소크라테스식 질문
행동 실험Clark & Beck (2010)흔들린 믿음을 몸으로 검증하는 SMART-Tiny 과제
ValidationLinehan (1993)감정 수용 + Normalization, 변화 강요 방지
Stuck PointCPT, Resick (1992)4유형 분류(자책·일반화·낙인·무력감)로 인지 진단

임상 순서 (Beck 표준)

  1. 진술 수용 (Validation)
  2. 회피 행동 + 왜곡된 믿음 포착 (정보 수집)
  3. 인지 재구성 (소크라테스식 질문 — 정답 안 줌)
  4. 믿음 흔들림 신호 확인 후 → 행동 실험 (SMART-Tiny, 5분 이내)
  5. 행동 결과 인용 → 스키마 전환 넛지
  6. 종결 + 연계처 안내
핵심 원칙: 인지 흔들기가 충분하지 않은 상태에서 행동 실험으로 넘어가지 않는다. 행동 실험은 흔들린 믿음을 검증하는 도구이지, 흔드는 도구가 아니다.

RAG 구조

학교 플랫폼(165.132.92.61/mh_class/)의 모듈형 라우팅 기능을 사용합니다. 단일 시스템 프롬프트 안에 ROUTER + COMMON + 다수 MODULE을 정의하고, ROUTER가 매 턴 발화 유형에 따라 적합한 모듈을 호출합니다.

전체 구조

  • ROUTER — 11개 우선순위 규칙
  • COMMON — 모든 모듈 공통 금지·말투 규칙
  • MODULE: SAFETY — 자살·자해 키워드 감지 시 1393 안내 (1차/재진입 분기)
  • MODULE: SAFETY_INDIRECT — 간접 위기 표현 감지 시 의사 확인
  • MODULE: INTAKE — 피해 진술 수용
  • MODULE: BELIEF_CAPTURE — 회피·믿음 포착 (세션 1회)
  • MODULE: COGNITIVE — 소크라테스식 인지 재구성
  • MODULE: EXPERIMENT — SMART-Tiny 행동실험 (세션 최대 2회)
  • MODULE: NUDGE — 실험 후 스키마 전환 넛지
  • MODULE: VALIDATE — 감정 수용 + Normalization
  • MODULE: CLOSE — 3분기 종결 (스키마 전환 / 종결 선언 / 부정 피드백 강제)
  • MODULE: FALLBACK — 미매칭·이탈·능력 밖 질문 처리

ROUTER 우선순위 (요약)

순위트리거호출 모듈
0간접 위기 표현SAFETY_INDIRECT
1자살·자해 키워드SAFETY
2부정 피드백 2회 누적CLOSE (강제)
3명시적 인지 변화 발화 또는 종결 선언CLOSE
4첫 진술INTAKE
5회피·믿음 미포착 (세션 1회 제한)BELIEF_CAPTURE
6믿음 강하게 유지COGNITIVE
7흔들림 신호 + 실험 2회 미만EXPERIMENT
8실험 수행 보고NUDGE
9강한 감정 표현VALIDATE
10미매칭·주제 이탈·능력 밖FALLBACK

절대 규칙 (요지)

  • COGNITIVE를 충분히 거치지 않고 EXPERIMENT 진입 금지
  • 행동실험 한 세션 최대 2회
  • 0–100 척도 한 세션 최대 2회
  • 척도 숫자 응답(예: "60")을 스키마 전환으로 해석 금지
  • 연계처 안내 출력 후 새 임상 작업(인지 흔들기·실험·척도) 금지
  • 모듈 이름·번호·진행 단계는 사용자에게 노출 금지
