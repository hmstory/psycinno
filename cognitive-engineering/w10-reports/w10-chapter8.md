# Ch8. Decision Making

## 0. Argument Spine (논증의 뼈대)

> **이 챕터의 한 줄 주장**: 인간의 의사결정은 정보처리 한계로 인해 체계적 편향을 보이며, 이를 전단부(진단)와 후단부(선택)로 분리해 이해해야 설계·훈련으로 개선할 수 있다.

**왜 이 순서로 개념을 배치했나**
먼저 DM을 정보처리 모델(Figure 8.1)로 해부하여 "전단부(진단)"와 "후단부(선택)"라는 두 무대를 설정한다. 그런 다음 전단부에서 인간이 어떻게 단서를 잘못 읽고(지각 편향), 잘못 통합하고(가중치 편향), 잘못 믿음을 업데이트하는지(앵커링·확증편향) 순서대로 쌓아 올린다. 후반부에서는 후단부 선택에서 기댓값 모델로부터 얼마나, 왜 이탈하는지(손실회피·프레이밍)를 보여준 뒤, 노력·메타인지·전문성 변수로 전체를 조율한다. 마지막으로 설계·훈련·자동화로 이 편향들을 줄이는 처방을 제시한다.

**Spine 아래에서 각 주요 개념의 역할**
- **Figure 8.1 (정보처리 모델)**: 챕터 전체의 지도 — 진단(전단부)과 선택(후단부)의 위치 설정
- **편향/휴리스틱 (5절)**: 전단부에서 인간이 기대치에서 이탈하는 이유들 — 메커니즘 설명
- **기댓값·프로스펙트이론 (6절)**: 후단부 이탈의 규범 기준 및 이탈 패턴
- **노력·메타인지 (7절)**: 두 무대를 관통하는 자원 제약 변수 — 왜 휴리스틱이 선택되는지
- **전문성 (8절)**: 반복 경험이 편향을 어떻게 조절하는지(또는 조절 못 하는지)
- **개선 방법 (9절)**: Spine의 결론부 — 위 진단들을 처방으로 전환

## 1. 챕터 개요

> 의사결정은 많은 정보를 처리해 하나의 행동을 선택하는 과정이며, 불확실성·시간·전문성이라는 세 차원에 의해 그 질이 결정된다.

인간의 DM은 정보처리 모델 안에서 **진단(전단부)**과 **선택(후단부)**으로 구분된다. 진단 단계에서는 단서를 통해 세계 상태에 대한 가설을 형성하고, 선택 단계에서는 그 진단에 기반해 행동을 고른다. 이 두 단계 모두 인지적 한계, 편향, 휴리스틱으로 인해 "최적" 결정에서 이탈한다. 공학심리학의 목표는 이탈의 원인을 이해하고 설계·훈련·자동화로 보완하는 것이다.

## 2. 섹션별 핵심 요약

### 2절. DM의 분류와 특징 (Classes and Features of DM)

DM의 3대 특징: **불확실성(Uncertainty)** — 결과가 확정되지 않은 정도, **시간(Time)** — 일회성 vs. 진화적 결정 + 시간 압박, **친숙도·전문성(Familiarity & Expertise)** — 전문가는 직관(System 1)으로 빠르게, 초보자는 분석(System 2)으로 느리게.

DM 연구의 3대 학파:
| 학파 | 초점 | 핵심 질문 |
|------|------|-----------|
| **규범적(Normative)** | 어떻게 해야 하나 | 기댓값 최대화 |
| **인지/정보처리** | 왜 편향이 생기나 | 휴리스틱의 원인 |
| **자연주의적(NDM)** | 실제 현장에서 어떻게 | 전문가의 실시간 결정 |

System 1(직관·전체론적)과 System 2(분석·숙고적)은 각각 **자연주의적 DM**과 **휴리스틱/편향 접근**에 대응한다.

### 3절. DM의 정보처리 모델 (Figure 8.1)

```
환경 → 선택적 주의/단서 필터링 → 지각 → 진단(H₁, H₂...) → 선택/반응선택 → 반응실행
                                   ↑                    ↑
                              장기기억              장기작업기억
                                              작업기억·인지
                                                    ↑
                              주의자원·노력 / 메타인지 (위에서 감시)
                              (확인 피드백 루프: 진단 → 단서 재탐색)
```

- **전단부(Front-end)**: 단서탐색 → 상황인식 → 진단
- **후단부(Back-end)**: 행동 옵션 생성 → 위험 평가 → 선택
- 진단이 틀리면 선택도 틀린다 → 전단/후단 실패 원인이 다르므로 해결책도 달라야 함
- **메타인지**: 자신의 지식 한계를 인식해 더 많은 단서를 탐색하는 것
- **피드백 루프**: 결과 → 진단 수정 → 전략 개선 (하지만 종종 지연·모호·선택적)

### 4절. "좋은" DM이란? (What is "Good" DM?)

3가지 기준:
1. **기댓값 극대화** (규범적 기준): 반복 시 최대 결과를 내는 결정
2. **좋은 결과를 낸 결정** (결과 기반): 불확실한 세계에서 운이 결과를 좌우 → **사후 편향(hindsight bias)** 함정
3. **전문가가 한 결정** (전문성 기반): 전문가도 특정 영역에서 편향 → 보장 안 됨

세 기준이 일치할수록 "좋은 DM" 판단이 쉬워지나, 불일치할 때는 과정 분석이 더 적절하다.

### 5절. 진단과 상황평가 (Diagnosis & Situation Assessment)

#### 5.1 지각에서의 추정 편향 (Estimating Cues: Perception)

**비율(Proportions)**: 중간 범위(0.05~0.95)에서는 비교적 정확하나 극단값에서는 **보수적 편향** (0과 1 쪽으로 당겨진다). 단, 극히 드문 사건은 직접 경험이 없을 경우 **과소평가** (Hertwig & Erev, 2009).

**외삽(Projections)**: 지수적 성장을 선형으로 외삽 → **보수적 편향** (Figure 8.2). 반면 비지수적 증가량에 대해서는 과잉반응(overreaction)도 발생.

**무작위성(Randomness)**: **도박사의 오류(gambler's fallacy)** — 연속된 동일 결과 후 다른 결과를 기대. **핫핸드 효과(hot hand)** — 농구 연승은 실제로는 독립 사건이나 연속성을 과대 지각.

설계 함의: 인간이 추정해야 하는 매개변수를 시스템이 직접 계산·표시하면 이 편향을 우회할 수 있다.

#### 5.2 증거 축적과 가설 형성 (Evidence Accumulation)

**Figure 8.3** — 정보 통합 과정:
- 각 단서는 세 속성을 가짐:
  1. **단서 진단성(Cue Diagnosticity, D)**: 단서가 가설 H₁ vs H₂를 얼마나 구별하는가 (0~1)
  2. **단서 신뢰성(Cue Reliability, R)**: 단서 자체가 믿을 만한가 (0~1)
  3. **단서 현저성(Physical Salience)**: 주의를 얼마나 끄는가
- **정보가치(Information Value) = D × R** → 이상적으로는 정보가치에 비례해 가중치 부여

4대 정보통합 작업: ① 선택적 주의(정보가치 순 가중), ② 통합(bottom-up), ③ 기대치 편향(top-down, LTM), ④ 반복 검증(iterative testing)

**4가지 취약성**:

| 취약성 | 내용 |
|--------|------|
| **5.2.1 단서 부재** | 없는 단서의 부재(not seen)를 진단에 활용 못함 |
| **5.2.2 정보 과부하** | 단서 수 증가 → 필터링 비용 증가 → 진단 질 저하; 자신감↑ 정확도↓ |
| **5.2.3 현저성 편향(Salience bias)** | 가장 밝고 큰 신호가 처리됨 — 현저성 ≠ 정보가치 |
| **5.2.4 as-if 휴리스틱** | 모든 단서를 동등한 정보가치로 처리 (Figure 8.4) → 진단성 차이 무시 |

**Figure 8.4 (as-if heuristic)**: x축=기준 상관(신뢰성), y축=진단 가중치. 최적(직선)은 선형 비례이나, 실제 인간(점선)은 고신뢰 단서를 과소 가중하고 저신뢰 단서를 과대 가중.

#### 5.3 장기기억의 역할: 기대와 휴리스틱

**대표성 휴리스틱(Representativeness heuristic)**: 관찰된 단서 패턴을 장기기억의 원형(prototype)에 매칭 → 가장 닮은 진단 선택. 문제: **기저율(base rate) 무시** — 질병 X가 희귀해도, 증상이 X와 4/5 일치하면 X로 진단.

**가용성 휴리스틱(Availability heuristic)**: 가설의 사전 확률을 기억에서 떠올리기 쉬운 정도로 추정. 영향 요인: 최근성(recency), 가설 단순성, 과거 경험의 정교화 정도. → **속성 대체(attribute substitution)**: 추상적 확률 대신 접근 가능한 속성(유사성, 평균, 변화량)으로 대체.

**베이지안 접근**: 대표성(사전확률) × 가용성(데이터 패턴) → 이상적으로 결합되어야 하나, 인간은 가용성에 따른 사전확률과 대표성에 따른 데이터 패턴을 휴리스틱적으로 처리.

#### 5.4 시간에 따른 믿음 변화

**앵커링 휴리스틱(Anchoring)**: 처음 형성된 가설에 고착(primacy 효과). 증거 순서가 a→b면 A 선호, b→a면 B 선호. 설계 함의: 정보를 순차적 대신 동시 제시하면 앵커링 완화.

**확증 편향(Confirmation Bias)**: 이미 믿는 가설을 확인하는 단서만 탐색, 반증 단서는 무시. "인지적 터널 비전" 유발. 사례: USS 빈센스 사건, 스리마일 섬 사고.

확증 편향의 4가지 원인 (Nickerson, 1998):
1. 긍정 정보가 부정 정보보다 인지적으로 처리 쉬움
2. 일관성에 대한 동기적 욕구
3. 믿음에서 비롯된 행동 결과에 집중 → 진실 탐색보다 결과 최적화
4. 자기충족적 예언 가능성 (선택이 결과를 확인)

**결정 피로(Decision Fatigue)**: 반복 결정 → 인지 자원 고갈 → 기본값(effort-lite) 전략으로 이동. 사례: 가석방 위원회 오전 75% → 오후 25% 승인율 (Danziger et al., 2011).

#### 5.5 편향·휴리스틱의 함의

- 많은 휴리스틱은 **적응적** — 빠르고 자원 절약적이며 대부분의 경우 충분히 정확
- 시간 제약 환경에서 휴리스틱 사용은 **필수**
- 편향은 특정 조건(훈련, 설계)으로 **조절 가능**

### 6절. 행동 선택 (Choice of Action)

#### 6.1 확실성 하의 선택 (Certain Choice)

**보상적 모델(Compensatory model)** — Figure 8.5:
1. 각 속성(attribute)에 중요도 순위 부여
2. 각 객체의 각 속성 값 평가
3. (값 × 중요도) 합산
4. 합이 가장 높은 객체 선택

예: Object A = 2×1 + 3×4 = 14, Object B = 3×1 + 1×4 = 7 → A 선택

약점이 다른 강점으로 **보완(compensate)** 가능하다는 가정.

**만족화(Satisficing, Simon, 1955)**: "충분히 좋은" 옵션에서 멈춤 — 시간 압박 시 현실적 전략.

**측면별 제거(Elimination by Aspects, EBA; Tversky, 1972)**: 가장 중요한 속성을 기준으로 기준치 미달 옵션 순차 제거 → 남은 옵션 중 선택. 결정 피로 시 지배적 전략.

#### 6.2 불확실성 하의 선택: 기댓값 모델

**Figure 8.6** — 불확실성 하의 DM 행렬:
- 열(column): 세계 상태 A, B, C... (각각 확률 Pₐ, P_b...)
- 행(row): 결정 옵션 1, 2...
- 셀: 각 상태에서 각 선택의 결과값 V

**기댓값(EV) = Σ(V × P)** → 가장 높은 EV의 대안 선택

이 모델은 반복 결정에서 장기적으로 최대 결과를 보장하나, 단일 결정·주관적 가치·인간의 확률 지각 왜곡으로 인해 실제 행동과 괴리.

#### 6.3 불확실한 선택에서의 편향

**직접 인출(Direct Retrieval / RPDM)**: 유사 과거 상황 인식 → 과거에 효과적이었던 행동 직접 선택 (System 1). 전문가의 시간 압박 환경에서 지배적. 선택지 명시적 비교 불필요.

**손실회피(Loss Aversion) & 프로스펙트이론** (Kahneman & Tversky, 1984):

Figure 8.7 — 가치-효용 함수:
- x축: 객관적 가치(이득 우측, 손실 좌측)
- y축: 주관적 효용
- **손실 구간이 이득 구간보다 기울기가 더 가파름** → 같은 금액의 손실이 이득보다 더 큰 효용 변화
- **부존효과(endowment effect)**: 이미 가진 것을 팔려면 살 의향가보다 더 많이 요구
- 두 구간 모두 원점에서 멀어질수록 기울기 감소 → Weber의 법칙 반영

**시간 할인(Temporal Discounting)**: 미래 이득을 현재 이득보다 저평가 → 단기 이득 선호. 개인차 큼.

**확률 지각(Perception of Probability)** — Figure 8.8:
- x축: 객관 확률, y축: 주관 확률
- 희귀 사건(묘사 기반): **과대평가** → 보험 구매, 도박 참여 설명
- 희귀 사건(경험 기반): **과소평가** (Hertwig & Erev, 2009)
- 중간 확률 범위: **대체로 과소평가** → "확실한 것" 선호 편향
- **sluggish beta**: 확률 변화에 둔감 → 기준점 조정 불충분

**프레이밍 효과(Framing Effect)** (Tversky & Kahneman, 1981):
- 동일한 결과를 **이득 프레임**으로 제시 → 위험 회피
- **손실 프레임**으로 제시 → 위험 추구
- 예: "98% 생존" vs "2% 사망" — 의사는 전자에서 치료를 더 선택
- **매몰 비용 편향(Sunk cost bias)**: 이미 투자한 비용을 손실 프레임으로 보아 계속 투자 ("나쁜 돈을 좋은 돈 뒤에 던진다")

#### 6.4 안전 행동의 결정 (Decision to Behave Safely)

안전 수칙 준수 = "확실한 비용(cost of compliance)" vs "희귀한 위험(risky outcome)"
- 가용성 휴리스틱: 사고를 직접 경험하지 않으면 위험 과소평가
- 대표성: 재앙적 결과의 확률 자체에 둔감 → **심각성**이 확률보다 위험 지각에 더 큰 영향
- 위험 과대평가 3요인: ① publicity(매체 노출) ② dread factor(통제 불가·파국) ③ unknown factor(새 기술)
- 개입 전략: 위반 행동에 **가벼운 즉각 페널티(gentle reminder)** → 희귀 결과 대신 빈번한 경험으로 연결

### 7절. 노력과 메타인지 (Effort & Meta-Cognition)

#### 7.1 노력 (Effort)

**성과-자원 함수(Performance-Resource Function)** — Figure 8.9:
- x축: 투입 자원(노력), y축: 의사결정 성과
- 전체 알고리즘(보상적 모델): 노력 증가 시 성과 계속 향상, 고자원 투입에서 최고 성과
- 휴리스틱: 자원이 낮을 때 알고리즘보다 **효율(정확도/자원)이 높음** → 자원 제약 상황에서 합리적 선택
- **개연 모델(Contingent Model, Payne et al., 1993)**: 가용 시간(자원)에 따라 전략이 결정됨

#### 7.2 메타인지와 과신 (Meta-Cognition & Overconfidence)

**과신 편향(Overconfidence Bias)**: 자신의 진단·판단의 정확성을 실제보다 높게 추정.

사례:
- 평균 운전자: 자신이 상위 25% 안전 운전자라고 믿음 (→ 실제 50%여야 맞음)
- 예측 정확도 60%이나 자신감 80% (Fischhoff, 1977)
- **계획 오류(Planning Fallacy)**: 완료에 필요한 시간·자원 낙관적 과소평가

**정확도-자신감 보정 공간 (Figure 8.10)**:
- x축: 실제 성과(true accuracy), y축: 자신감(estimated accuracy)
- 대각선: 완벽 보정 — 대부분 사람은 위-왼쪽(과신 영역)
- 성과를 저하시키는 변수가 자신감은 저하시키지 않을 때 과신 발생(상단 점선 화살표)

과신을 증폭하는 4가지 변수:
1. **진단 난이도**: 단서 모호성 증가 → 정확도↓, 자신감 유지
2. **증거 신뢰성**: 낮은 신뢰성에 둔감 → 자신감 부당 유지
3. **상관된 정보원**: 정보원 추가 → 자신감↑, 정확도↑ 안 함
4. **정보원 수 증가**: 자신감 증가, 진단 정확도는 정체

### 8절. 경험과 전문성 (Experience & Expertise)

**자연주의적 DM (NDM)**: 실제 환경에서 전문성을 가진 사람이 어떻게 결정하는가.

전문가의 전단부: **RPDM(Recognition-Primed Decision Making)** — 상관된 단서 패턴 자동 인식 → 상황을 즉각 분류 → "홀리스틱 DM"(System 1)

전문가의 후단부: 장기기억에서 효과적 행동을 직접 인출 → 빠른 반응, 명시적 비교 불필요

**Table 8.1 (Shanteau, 1992) — 전문성이 도움이 되는 영역 vs 안 되는 영역**:

| "좋은" DM 영역 | "나쁜" DM 영역 |
|----------------|----------------|
| 기상 예보 | 임상 심리사 |
| 체스 마스터 | 인사 선발 담당자 |
| 의사 | 가석방 위원 |
| 회계사 | 주식 중개인 |
| **특성: 동적, 사물 대상, 반복, 피드백 有, 분해 가능** | **특성: 정적, 사람 대상, 예측 어려움, 피드백 少** |

피드백이 학습을 방해하는 3가지 이유 (Einhorn & Hogarth, 1978):
1. **모호한 피드백**: 좋은 과정도 나쁜 결과 가능 (운)
2. **지연된 피드백**: 결정 시 사용한 전략을 잊은 후 결과 도달
3. **선택적 피드백**: 거절된 케이스(Figure 8.11 "물고기가 도망쳤다")의 결과를 볼 수 없음 → 확증 편향 강화

### 9절. DM 개선 방법 (Improving Decision Making)

#### 9.1 편향 제거 훈련 (Training Debiasing)

- 단순히 편향을 가르치는 것(이 장을 읽는 것)은 불충분 — "inert knowledge" 위험
- 효과적 접근: **구체적 사례 + 연습 + 특정 디바이어싱 전략**
- 성공 사례: "반대 고려하기(consider the opposite)" → 과신·확증편향 완화
- 즉각적·포괄적 피드백 제공 → 모든 4분면 정보(Figure 8.11) 동시 제공

#### 9.2 절차화 (Proceduralization)

진단·선택을 단계별로 구조화한 절차 처방. 예: 멕시코시티 공항 입지 선정, 해안 개발 정책 타협.

Leher (2010)의 효과적 DM 5전략:
1. 단순한 문제 → 직관(Type 1) 가능, Type 2도 도움
2. 새로운 문제 → 반드시 Type 2 분석
3. 불확실성 수용 — 경쟁 가설 항상 유지
4. 전문 영역에서는 직관("gut") 신뢰 가능 — Type 2가 감시
5. 메타인지 훈련 — 생각에 대해 생각하기

#### 9.3 디스플레이 (Displays)

- **근접 호환성 원리(Proximity Compatibility Principle)**: 진단에 통합 필요한 정보원은 동시에·근접하여 표시 → 순차 편향(앵커링) 방지
- 생태학적 디스플레이(Ecological displays): 복잡 시스템의 이상 상태를 emergent feature로 시각화 → 진단 지원 (Ch.4 연결)
- 위험 정보를 수치·텍스트보다 그림(stick figures 등) 형태로 제시 → 더 보정된 위험 결정

#### 9.4 자동화·결정 지원 도구 (Automation & Decision Support)

- 전단부 지원: 진단·상황평가 자동화
- 후단부 지원: 치료·행동 권고 시스템
- 최적: 인간이 관련 예측 변수 식별 + 폴라리티 결정 → 컴퓨터가 통합·기준값 도출 (Fischhoff, 2002)

## 3. 핵심 개념 정의

| 용어 | 정의 | 관련 섹션 |
|------|------|-----------|
| **불확실성(Uncertainty)** | 결과의 가능한 상태가 확정되지 않은 정도; 위험(risk)을 수반 | 2 |
| **규범적 DM (Normative DM)** | 기댓값 극대화 등 최적 기준에 따른 DM | 2, 6.2 |
| **자연주의적 DM (NDM)** | 현장 전문가가 실시간으로 수행하는 경험 기반 DM | 2, 8 |
| **진단(Diagnosis)** | 단서를 기반으로 세계 현재/미래 상태에 대한 가설 형성 과정 | 3, 5 |
| **단서 진단성(Cue Diagnosticity, D)** | 단서가 H₁ vs H₂를 구별하는 정도 (0~1) | 5.2 |
| **단서 신뢰성(Cue Reliability, R)** | 단서 자체가 믿을 만한 정도 (0~1) | 5.2 |
| **정보가치(Information Value)** | D × R; 단서에 부여해야 할 이상적 가중치 | 5.2 |
| **현저성 편향(Salience Bias)** | 정보가치가 아닌 물리적 두드러짐에 의해 단서가 처리됨 | 5.2.3 |
| **as-if 휴리스틱** | 모든 단서를 동등한 정보가치로 취급 | 5.2.4 |
| **도박사의 오류(Gambler's Fallacy)** | 독립 확률 사건에서 이전 결과가 다음에 영향을 준다는 잘못된 믿음 | 5.1.3 |
| **대표성 휴리스틱** | 단서 패턴이 프로토타입과 유사한 진단을 선택; 기저율 무시 | 5.3.1 |
| **가용성 휴리스틱** | 기억에서 떠올리기 쉬운 정도로 사전 확률 추정 | 5.3.2 |
| **앵커링 휴리스틱** | 초기 가설에 고착; 이후 증거가 충분히 업데이트를 못 함 | 5.4.1 |
| **확증 편향(Confirmation Bias)** | 믿음을 확인하는 단서만 탐색, 반증 단서 무시 | 5.4.2 |
| **결정 피로(Decision Fatigue)** | 반복 결정으로 인지 자원 고갈 → 기본값 전략으로 이동 | 5.4.3 |
| **사후 편향(Hindsight Bias)** | 결과를 안 후 이전에도 알 수 있었다고 믿는 편향 | 4 |
| **기댓값(Expected Value, EV)** | Σ(확률 × 결과값); 반복 결정의 장기 최적 기준 | 6.2 |
| **만족화(Satisficing)** | "충분히 좋은" 옵션에서 탐색 중단 (Simon, 1955) | 6.1 |
| **측면별 제거(EBA)** | 가장 중요한 속성 기준으로 옵션 순차 제거 (Tversky, 1972) | 6.1 |
| **손실회피(Loss Aversion)** | 같은 금액의 손실이 이득보다 더 큰 심리적 영향 | 6.3.2 |
| **부존효과(Endowment Effect)** | 이미 소유한 것의 가치를 구매 의향가보다 높게 평가 | 6.3.2 |
| **프로스펙트이론(Prospect Theory)** | 손실회피 + 확률 가중 함수를 통합한 DM 이론 (Kahneman & Tversky, 1984) | 6.3.2 |
| **시간 할인(Temporal Discounting)** | 미래 이득을 현재 이득보다 할인하여 평가 | 6.3.3 |
| **프레이밍 효과(Framing Effect)** | 동일 결과를 이득/손실로 어떻게 제시하느냐에 따라 선택이 달라짐 | 6.3.5 |
| **매몰 비용 편향(Sunk Cost Bias)** | 이미 지출된 비용이 미래 결정에 영향 — 합리적으로는 무관해야 함 | 6.3.5 |
| **과신 편향(Overconfidence Bias)** | 자신의 진단·판단 정확도를 실제보다 높게 평가 | 7.2 |
| **계획 오류(Planning Fallacy)** | 완료 시간·자원을 낙관적으로 과소추정 | 7.2 |
| **RPDM (인식-점화 DM)** | 전문가가 상황 인식 후 기억에서 적절 행동을 직접 인출 | 6.3.1, 8 |
| **홀리스틱 DM (Holistic DM)** | 전문가의 전체론적·직관적 진단 (System 1) | 8 |
| **편향 제거(Debiasing)** | 훈련·절차로 인지 편향을 줄이는 기법 | 9.1 |
| **절차화(Proceduralization)** | 진단·선택 단계를 명시적 절차로 구조화 | 9.2 |

## 6. 퀴즈 후보

<!-- K-콘텐츠 앵커 가능 항목 표시 -->

1. **DM의 전단부(front-end)와 후단부(back-end)의 차이**는 무엇이며, 왜 실패 원인을 구분하는 것이 중요한가?
   → 전단부=진단(세계 상태 파악), 후단부=선택(행동 결정). 진단 실패(잘못된 상황인식)와 선택 실패(위험 평가 오류)는 원인이 달라 처방도 달라야 한다.

2. 단서의 **정보가치(Information Value)**를 계산하는 공식과, 인간이 이를 최적으로 사용하지 못하는 이유는?
   → IV = D × R. as-if 휴리스틱으로 단서를 등가중 처리; WM 부담 감소를 위한 인지 단순화.

3. **확증 편향(Confirmation Bias)**이 USS 빈센스 사건에서 어떻게 작동했는가?
   → 레이더 요원이 항공기를 적대적으로 가정한 후, 이를 반박하는 레이더 데이터(중립 비행 패턴)를 무시하고 가설 확인 단서만 처리 → 격추 결정.

4. **도박사의 오류(Gambler's Fallacy)**와 **핫핸드 효과(Hot Hand)**는 같은 무작위성 오지각의 어떤 측면을 반영하는가?
   → 둘 다 독립 사건들에서 패턴을 지각. 도박사 오류=교대 기대, 핫핸드=연속 기대. 농구에서 연속 성공은 사실상 독립 사건.

5. K-콘텐츠 앵커 🎬: **오징어게임**에서 참가자들이 게임을 계속하는 결정은 어떤 DM 편향으로 설명되는가?
   → 매몰 비용 편향(이미 잃은 것) + 프레이밍(탈락=확실한 손실 vs 계속=이득 기회) + 손실회피 → 위험 추구 선택.

6. **기댓값 모델(EV)**로 선택해야 하는 경우와, 인간이 이 모델에서 이탈하는 3가지 이유는?
   → EV=Σ(V×P), 반복 결정 장기 최적. 이탈 이유: ① 손실회피(주관적 효용이 선형 아님) ② 확률 지각 왜곡 ③ 단일 결정에서 최소 손실 추구.

7. **프레이밍 효과(Framing Effect)**에서 이득 프레임과 손실 프레임이 각각 어떤 리스크 선호를 유발하는가?
   → 이득 프레임 → 위험 회피(확실한 이득 선호). 손실 프레임 → 위험 추구(확실한 손실 회피). Figure 8.8의 곡선 기울기 차이로 설명.

8. **과신 편향(Overconfidence)**을 증폭하는 4가지 변수를 Figure 8.10과 연결하여 설명하라.
   → ① 진단 난이도: 정확도↓, 자신감 유지(상단 점선) ② 저신뢰 증거에 둔감 ③ 상관 정보원: 자신감↑ 정확도↑ 안함(실선) ④ 정보원 수 증가: 자신감↑ 정확도 정체.

9. **Shanteau(1992)**에 따르면 전문성이 DM을 개선하는 영역과 그렇지 않은 영역을 가르는 특성은 무엇인가?
   → 동적·반복·피드백 풍부·분해 가능 → 전문성 효과. 정적·사람 대상·피드백 빈약 → 전문성 효과 없음.

10. **안전 행동 결정**에서 위험을 과소평가하게 만드는 메커니즘 3가지와, 이를 역이용한 개입 전략은?
    → 가용성(사고 미경험), 대표성(재앙 확률 무감), 비용 현저성(순응 비용이 즉각적). 개입: 위반 행동에 가벼운 즉각 페널티(gentle reminder) — 희귀 결과를 빈번한 경험으로 연결.
