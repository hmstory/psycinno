# PRD: 칼럼 → 인스타그램 카드뉴스 자동 변환기

**작성자**: 김형모  
**작성일**: 2026-05-22  
**상태**: Draft v1.0  
**프로젝트 코드명**: CardCast

---

## 1. 문제 정의

심리·과학 칼럼을 쓰는 창작자가 글을 인스타그램에 올리려면:

1. 긴 글을 카드 단위로 직접 끊는다
2. Canva 등에서 디자인을 일일이 만든다
3. 이미지를 내보내서 업로드한다

**이 과정이 칼럼 쓰는 것보다 오래 걸린다.** 결국 좋은 글이 인스타에 올라가지 못하고 묻힌다.

---

## 2. 목표

칼럼 텍스트를 붙여넣으면:
- AI가 카드 단위로 요약·분할하고
- 인포그래픽 스타일 카드를 자동 렌더링하고
- PNG(정적) / MP4(애니메이션) 파일로 바로 다운로드

**핵심 지표**: 칼럼 1편 → 카드뉴스 완성까지 5분 이내

---

## 3. 대상 사용자

| 구분 | 설명 |
|---|---|
| **1차 사용자** | 김형모 본인 (심리·인지공학 칼럼) |
| **2차 사용자** | 유사 창작자 (과학·심리·에세이 계열) |
| **공통 특징** | 글은 잘 쓰지만 디자인 툴이 번거로운 사람 |

---

## 4. 핵심 기능 (MVP)

### 4-1. 카드 분할 · 요약 (Claude API)

- 칼럼 전문을 입력받아 카드 단위로 분할
- 각 카드: 제목 1줄 + 본문 3~5줄 이내로 요약
- 카드 타입 자동 판별:
  - `text` — 일반 텍스트 카드
  - `table` — 2×2 표, 비교표 등
  - `chart` — 그래프·도표 (ROC, 정규분포 등)
  - `animated` — 움직이는 그래프 (MP4)

### 4-2. 정적 카드 렌더링 (HTML + Playwright)

- 카드 타입별 HTML 템플릿 자동 생성
- 인포그래픽 스타일: 아이콘, 색상 강조, 카드 번호
- Playwright로 1080×1080 PNG 스크린샷
- 카드 전체 ZIP 다운로드

### 4-3. 애니메이션 카드 (Remotion)

- `chart` / `animated` 타입 카드를 MP4로 렌더링
- 지원 애니메이션:
  - ROC 곡선이 그려지는 영상
  - 정규분포가 이동하는 영상
  - 2×2 표가 하나씩 나타나는 영상
- 해상도: 1080×1080, 30fps, 3~5초

### 4-4. 웹 UI

- 텍스트 입력창 (칼럼 붙여넣기)
- 카드 미리보기 (좌우 스와이프)
- 개별 카드 수동 편집 가능
- PNG / MP4 개별 다운로드 + 전체 ZIP

## 5. 사용자 흐름 (Happy Path)

```
[칼럼 텍스트 입력]
        ↓
[Claude API: 카드 분할·요약·타입 판별]

[카드 미리보기 — 수정 가능]
        ↓
     ┌──┴──┐
   정적   애니메이션

     └──┬──┘

  [인스타그램 업로드]
```

## 6. 기술 스택

| 레이어 | 기술 | 이유 |
|---|---|---|
| **프레임워크** | Next.js (React) | Remotion과 통합 용이 |
| **AI** | Claude API (claude-sonnet-4-6) | 카드 분할·요약 |
| **정적 렌더링** | Playwright | HTML → PNG 자동화 |
| **애니메이션** | Remotion | 코드로 영상 생성 |
| **스타일** | Tailwind CSS | 빠른 UI |
| **배포** | 로컬 우선 → 추후 Vercel | MVP는 로컬 |

## 7. 카드 디자인 스펙

| 항목 | 값 |
|---|---|
| 사이즈 | 1080 × 1080 px (1:1) |
| 스타일 | 인포그래픽 (아이콘 + 색상 강조 + 카드 번호) |
| 폰트 | Noto Sans KR (한국어), Inter (영문) |
| 배경 | 흰색 또는 다크 모드 선택 |
| 워터마크 | `@작성자명` (우하단, 선택) |
| 카드 수 | 칼럼 길이에 따라 자동 (보통 6~12장) |

## 8. Claude API 프롬프트 설계

```
시스템: 당신은 칼럼을 인스타그램 카드뉴스로 변환하는 전문가입니다.

입력: [칼럼 전문]

출력 형식 (JSON):
{
  "cards": [
    {
      "index": 1,
      "type": "text | table | chart | animated",
      "title": "카드 제목 (15자 이내)",
      "body": "본문 (80자 이내)",
      "data": { ... }  // table/chart일 때 구조화된 데이터
    }
  ]
}

규칙:
- 첫 카드는 훅 (독자가 왜 읽어야 하는지)
- 마지막 카드는 핵심 요약 + CTA
- 표·그래프가 있으면 chart 타입으로
- 한 카드에 개념 하나만
```
